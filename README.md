##Typing Tutor
#Description

Typing Tutor is an interactive program designed to improve typing speed and accuracy. It helps users practice typing by presenting random paragraphs or sentences for them to type. The program tracks typing speed, errors, and overall performance, providing useful feedback to enhance typing skills. Ideal for beginners and advanced users alike, this tool makes typing practice engaging and measurable.

##Features
Random paragraph selection for varied practice.
Real-time tracking of typing speed (words per minute) and accuracy.
Error highlighting to identify commonly mistyped words.
User-friendly interface with clear instructions.
Option to restart practice sessions for continuous improvement.
How to Use

Run the program using your preferred C compiler:

gcc typing_tutor.c -o typing_tutor
./typing_tutor
Read the instructions displayed at the start.
Type the paragraph exactly as shown.
After finishing, the program displays:
Typing speed (WPM)
Number of errors
Accuracy percentage
Choose whether to retry with a new paragraph or exit the program.
Sample Output
Type the following paragraph:
"The quick brown fox jumps over the lazy dog."

Your typing:

Results:
